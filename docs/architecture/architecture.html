God class decomposition

  • Ragi core: Reduced from ~800 LOC to ~350 LOC thin delegating facade.

Performance

Reliability

Pooling & Validation

  • LLMClient: Single shared connection pool with exponential backoff retry.
  • RagiConfig: Pydantic validation with extra="forbid" to prevent silent typos.
  • E2E verified: 306 unit and integration test cases passing.
